<purpose>
    Reusable prompt template for grok-4.20-multi-agent-xhigh deep research through just-prompt.
    Harvested from the research-workflow grok_research tool config (workflow.toml) so other
    projects do not have to re-derive it. Chinese community on linux.do calls this model
    "传奇搜索大王"; it is especially strong for real-time X data plus academic paper, policy,
    official report, and market synthesis. Treat it as the first-layer deep research tool.
</purpose>

<usage_notes>
    - Non-streaming and slow. Use it when current external evidence quality matters and
      latency is acceptable. For streaming-friendly quick lookups, use a normal chat model.
    - Fallback chain when this model is unreachable or times out:
      grok_research -> Exa -> Bocha -> default web search.
    - Prefer English prompts for stronger consistency; ask explicitly for publication
      dates and source names, and instruct the model to separate verified facts from
      inference. Ask for a fixed output structure so the result is downstream-parseable.
    - Default gateway timeout for grok-4.20-multi-agent-xhigh is 1200s in just-prompt;
      raise it via `options.timeout` only when truly needed.
</usage_notes>

<system_prompt_suggestion>
    Prefer primary sources, include concrete publication dates, and separate verified
    facts from inference. Return a single consolidated report; do not narrate the process.
</system_prompt_suggestion>

<deep_research_template>
    Perform a comprehensive 16-agent Realtime Multi-Agent Deep Research in xhigh mode on
    [主题]. Leave no stone unturned.

    Harper team: be exhaustive with web, X (use advanced operators for latest posts),
    academic papers, official reports.

    Benjamin: verify all technical/financial/logical claims.

    Lucas: ruthlessly challenge assumptions and explore contrarian scenarios.

    Follow strict process: decompose -> parallel research -> multiple rounds of debate ->
    consensus synthesis.

    Deliver a professional-grade report equivalent to a top consulting firm team working
    for days. Structure: Executive Summary, Detailed Analysis (use tables for comparisons),
    Counterarguments & Limitations, Actionable Insights, Complete References with links
    where available.
</deep_research_template>

<output_contract>
    Synthesized research text. May include citations, source names, dates, or caveats
    depending on gateway output. Not streaming; wait for the full result. Treat timeouts
    or gateway errors as a reason to fall back to the next search provider.
</output_contract>
